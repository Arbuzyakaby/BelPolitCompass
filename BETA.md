# Путь к бете

Alpha 0.6 — последняя альфа. Следующая версия — **Beta 0.9**: функции заморожены, сайт показывается
людям, собираются отзывы, исправляются ошибки. После беты — версия 1.0.

## Что значит «бета» для этого проекта

- **Новых крупных функций нет.** Только исправления, тексты, данные и доступность.
- **Главное — данные.** Проект политический: фактическая ошибка опаснее бага в коде.
- **Отзывы собираются открыто** — через формы на GitHub, без аналитики и слежки на сайте.

## Готово к бете ✅

| Область | Состояние |
| --- | --- |
| Функции | Компас с 4 осями, карточки 14 партий, тест на 40 вопросов, аналитика, история, методология, «О проекте» |
| Качество | Модульные и сквозные тесты на компьютере, телефоне и планшете; GitHub Actions на каждый пуш |

| Публикация | https://arbuzyakaby.github.io/BelPolitCompass |
| Обратная связь | «Не согласны с оценкой?» в каждой карточке; шаблоны обращений в `.github/ISSUE_TEMPLATE` |

## Осталось до Beta 0.9 ⏳

1. **Проверить фактические данные каждой партии**: лидер, год основания, статус, дата ликвидации, мандаты.
   Особенно — лидер РПТС (данные на 2024 год) и точные даты ликвидации партий в 2023 году.
2. **Обосновать каждую координату**: 14 партий × 4 оси = 56 оценок. У каждой — короткое пояснение и источник
   (программа, заявление, голосование). Показывать в карточке партии кнопкой «Почему здесь?».
3. **Вычитать формулировки теста** с людьми разных взглядов: нет ли наводящих вопросов и перекоса в одну сторону.
4. **Проверить на реальных устройствах**: iPhone (Safari), Android (Chrome), Windows (Edge), экранные дикторы
   VoiceOver и NVDA.
5. **Поделиться результатом теста**: ссылка или карточка-картинка — главный способ, которым такие сайты
   распространяются.

## Как проходит бета

1. Сайт показывается 10–20 людям с разными политическими взглядами.
2. Отзывы приходят через формы на GitHub: «Позиция партии», «Ошибка в данных», «Что-то не работает».
3. Обоснованные правки данных принимаются с указанием источника; спорные — обсуждаются в issue.
4. Когда новых серьёзных замечаний нет две недели подряд — выходит 1.0.

## Как помочь

- Нашли ошибку или не согласны с оценкой — откройте карточку партии и нажмите «Не согласны с оценкой?».
- Умеете программировать — присылайте pull request: данные лежат в `js/data.js`, `npm test` проверит остальное.
