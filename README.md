# BelPolitCompass

> Интерактивный политический компас белорусских партий · **Alpha 0.4**

Карта белорусской политики в четырёх измерениях: вместо классического «лево-право × авторитаризм-либертарианство»
используются оси, отражающие реальные линии раскола в Беларуси.

## Оси

| Ось | −10 | +10 | Что измеряет |
| --- | --- | --- | --- |
| **Геополитический вектор** | Восток | Запад | Союзное государство, ЕАЭС, ОДКБ ↔ сближение с ЕС |
| **Модель власти** | Горизонталь | Вертикаль | Парламентская республика и самоуправление ↔ сильная президентская власть |
| **Экономическая модель** | Госсектор | Рынок | Госпредприятия и плановое регулирование ↔ приватизация и свобода предпринимательства |
| **Идентичность** | Советская | Национальная | Советская память, приоритет русского языка ↔ белорусский язык, наследие ВКЛ и БНР |

На компасе можно выбрать любую пару осей.

## Партии

**Действующие (4)** — с мандатами в Палате представителей VIII созыва (2024):
«Белая Русь» (51), РПТС (8), КПБ (7), ЛДПБ (4). Беспартийных депутатов — 40.

**Вне системы (10)** — ликвидированы в ходе перерегистрации 2023 года или так и не зарегистрированы:
Партия БНФ, ККП–БНФ, ОГП, «Справедливый мир», БСДП (Грамада), «Зелёные», Аграрная партия,
Патриотическая партия, БХД, Партия свободы и прогресса.

## Вкладки

Все разделы находятся на одной странице и разложены по вкладкам. Адрес страницы всегда соответствует
открытой вкладке, поэтому ссылкой можно поделиться, а кнопки «Назад» и «Вперёд» браузера работают.

| Вкладка | Адрес | Что внутри |
| --- | --- | --- |
| Главная | `#home` | Мини-компас, три шага для начала, места в парламенте, кнопка упрощённого режима |
| Компас | `#compass` | Компас с выбором осей, список партий и карточка партии |
| Тест | `#quiz` | Тест «Где я на компасе»: 40 утверждений и результат |
| Аналитика | `#analytics` | Парламент, доли мест, рейтинг по оси, радар, разрыв лагерей, матрица близости |
| История | `#timeline` | Партийная система с 1988 года |
| Оси | `#method` | Почему выбраны именно эти оси |
| О проекте | `#about` | Методика, ограничения, вопросы, словарь, версии, цитирование — с содержанием |

Ссылки на пункты внутри вкладки (`#faq`, `#cite`, `#about-sim`…) сами открывают нужную вкладку.
Вкладки переключаются стрелками ← →, Home и End. При печати и без JavaScript видны все разделы подряд.

## Возможности

- 🧭 **Компас** с выбором любых двух осей, плавным перемещением точек, оболочками лагерей и подсказками.
  Точки — настоящие кнопки: до каждой партии можно дойти клавишей Tab
- 🙋 **Тест «Где я на компасе»**: 40 утверждений, по 10 на ось, живая точка во время прохождения,
  результат со сходством с партиями и точкой «Вы» на большом компасе. Ответы хранятся только в браузере
- 🃏 **Карточка партии**: по нажатию на партию список сменяется подробной карточкой (листание стрелками,
  свайпами, клавиатурой). На компьютере — переворот, на телефоне — плавная смена без вложенной прокрутки
- 📊 **Аналитика**: полукруг парламента, доли мест, рейтинг по оси, радар сравнения, разрыв между лагерями,
  матрица близости. Под каждой диаграммой — те же данные таблицей
- 🕰 **История** партийной системы с 1988 года
- ℹ️ **О проекте** с новым содержанием: 15 пунктов, подсветка текущего при прокрутке, полоска прочитанного
- 💡 **Упрощённый режим** — пояснение простыми словами к каждой строке: к партиям, осям, вопросам теста
  (что значит термин и куда сдвинется точка), вариантам ответа, диаграммам и событиям
- ♿ **Специальные возможности** — см. ниже
- ⚙️ **Настройки**: тема, размер текста в четыре ступени, подсказки, режим анимаций, удаление данных
- 👋 **Тур для новичков** на 12 шагов, который сам переключает вкладки
- Строгий аналитический дизайн, светлая и тёмная темы, адаптив от 320 px

## Специальные возможности

Кнопка с человечком в шапке открывает вкладку настроек «Спецвозможности».

| Группа | Возможности |
| --- | --- |
| Быстрые профили | Слабое зрение · Дислексия · Моторика · Экранный диктор · Без движения · Просто и понятно |
| Зрение | Контрастность (обычная, повышенная, максимальная), удобочитаемый шрифт, увеличенные интервалы, подчёркнутые ссылки, крупный курсор, палитра для дальтоников |
| Чтение | Линейка для чтения, озвучивание текста (три скорости), таблицы данных под диаграммами |
| Управление | Крупные кнопки 44 × 44, заметная рамка фокуса, отключаемый автопереход в тесте, справка по клавиатуре |

Весь сайт проходится с клавиатуры, у всех элементов есть подписи для экранного диктора, смена вкладки
и ход теста объявляются вслух. Доступность каждой вкладки проверяется автотестом axe-core по WCAG 2.2 AA.

## Цвета партий

Цвета приглушены и заданы отдельно для светлой (`color`) и тёмной (`colorDark`) темы в `js/data.js`,
плюс палитра для дальтоников (`cvd`, `cvdDark`) на основе палитр Окабе–Ито и Пола Тола.
На компасе 14 партий одним цветом не различить, поэтому каждая точка всегда подписана — цвет лишь
дополняет подпись.

## Запуск

Сборка не нужна — чистые HTML, CSS и JavaScript без зависимостей.

```bash
# вариант 1: просто открыть index.html в браузере
# вариант 2: локальный сервер без зависимостей
npm start            # → http://localhost:4173
# или
python3 -m http.server 8000
```

Сайт можно опубликовать на GitHub Pages: Settings → Pages → Deploy from a branch → корень репозитория.

## Автотесты

```bash
npm install                      # Playwright и axe-core — только для тестов
npx playwright install chromium  # один раз, если браузер ещё не установлен
npm test                         # всё сразу
npm run test:unit                # 93 модульных теста, ~0,2 с, без браузера
npm run test:e2e                 # 516 сквозных тестов в Chromium
```

**Модульные** (`tests/unit`, встроенный `node --test`):

| Файл | Что проверяет |
| --- | --- |
| `core.test.js` | Склонения, форматирование чисел, сходство партий, подсчёт теста, раскладку точек без наложений, выпуклые оболочки, контраст WCAG |
| `boot.test.js` | Схему настроек, миграцию со старых версий, битый JSON, профили спецвозможностей, выбор вкладки по адресу |
| `data.test.js` | Данные: 14 партий, координаты −10…+10, цвета, 110 мест, баланс вопросов теста (5 «за» и 5 «против» на ось), пояснения для упрощённого режима |
| `html.test.js` | Разметку: уникальные id, все ссылки и ARIA-связи ведут на существующие элементы, вкладки и панели, версии, заголовки, безопасные внешние ссылки |
| `css.test.js` | Стили для каждой настройки, контраст текста ≥ 4,5 : 1 во всех темах, 3D-переворот только во время анимации, печать |

**Сквозные** (`tests/e2e`, Playwright) — каждый сценарий выполняется на трёх устройствах:
компьютер 1440 × 900, телефон (Pixel 7) и планшет в альбомной ориентации (Galaxy Tab S4).
Касания эмулируются через протокол Chromium, поэтому прокрутка пальцем проверяется по-настоящему.

| Файл | Что проверяет |
| --- | --- |
| `smoke` | Загрузка без ошибок, отсутствие горизонтальной прокрутки на каждой вкладке, 320 px, приватный режим |
| `tabs` | Вкладки, адреса, «Назад»/«Вперёд», клавиатура, фокус, соседние вкладки |
| `compass`, `card` | Оси, переключатели, точки-кнопки, карточка партии, листание, фильтр, фокус |
| `mobile` | Прокрутка списков и карточки пальцем, свайпы, матрица, лента вкладок, размер кнопок ≥ 24 px |
| `quiz` | Прохождение теста, клавиши 1–5, результат по формуле, сохранение прогресса, режим без автоперехода |
| `settings`, `a11y-features` | Все настройки, профили, контраст, шрифт, курсор, озвучивание (с подменой синтеза речи), таблицы |
| `simple` | Упрощённый режим во всех вкладках, пояснения у партий, вопросов и диаграмм |
| `charts`, `toc`, `tour` | Диаграммы и таблицы данных, содержание «О проекте», тур для новичков |
| `print-nojs` | Печать и работа без JavaScript |
| `axe` | Аудит доступности axe-core (WCAG 2.2 AA): каждая вкладка, тёмная тема, упрощённый режим, максимальный контраст, карточка, тест, настройки, тур |

Тесты запускаются в GitHub Actions при каждом пуше (`.github/workflows/tests.yml`).

## Структура

```
index.html            разметка: вкладки, настройки
css/styles.css        дизайн-система, темы, специальные возможности, печать
js/boot.js            до отрисовки: схема настроек, профили, выбор вкладки по адресу
js/data.js            оси, партии, координаты, вопросы теста, хронология — всё редактируется здесь
js/core.js            чистая логика: сходство, подсчёт теста, раскладка точек, контраст
js/tabs.js            вкладки, адреса страницы, объявления для экранного диктора
js/app.js             компас, список и карточка партии, общие утилиты
js/charts.js          графики и диаграммы на SVG, таблицы данных
js/quiz.js            тест «Где я на компасе»
js/settings.js        панель настроек и профили спецвозможностей
js/a11y.js            линейка для чтения и озвучивание
js/toc.js             содержание раздела «О проекте»
js/tour.js            тур для новичков и приглашение при первом визите
tests/unit/           модульные тесты (node --test)
tests/e2e/            сквозные тесты (Playwright + axe-core)
tests/serve.js        локальный сервер без зависимостей
assets/               иконка
```

Чтобы поправить позицию партии или добавить новую, достаточно изменить `js/data.js` —
тесты проверят, что данные корректны и ничего не сломалось.

## Методология и дисклеймер

Позиции партий — **экспертная оценка** по шкале от −10 до +10 на основе программ, публичных заявлений
и политической практики. Это не официальная позиция самих партий. Проект носит образовательный характер
и не агитирует ни за одну политическую силу.
