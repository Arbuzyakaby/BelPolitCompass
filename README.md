# BelPolitCompass

> Интерактивный политический компас белорусских партий · **Alpha 0.1**

Карта белорусской политики в четырёх измерениях: вместо классического «лево-право × авторитаризм-либертарианство»
используются оси, отражающие реальные линии раскола в Беларуси.

## Оси

| Ось | −10 | +10 | Что измеряет |
| --- | --- | --- | --- |
| **Геополитический вектор** | Восток | Запад | Союзное государство, ЕАЭС, ОДКБ ↔ сближение с ЕС |
| **Модель власти** | Горизонталь | Вертикаль | Парламентская республика и самоуправление ↔ сильная президентская власть |
| **Экономическая модель** | Госсектор | Рынок | Госпредприятия и плановое регулирование ↔ приватизация и свобода предпринимательства |
| **Идентичность** | Советская | Национальная | Советская память, приоритет русского языка ↔ белорусский язык, наследие ВКЛ и БНР |

На компасе можно выбрать любую пару осей.

## Партии

**Действующие (4)** — с мандатами в Палате представителей VIII созыва (2024):
«Белая Русь» (51), РПТС (8), КПБ (7), ЛДПБ (4). Беспартийных депутатов — 40.

**Вне системы (10)** — ликвидированы в ходе перерегистрации 2023 года или так и не зарегистрированы:
Партия БНФ, ККП–БНФ, ОГП, «Справедливый мир», БСДП (Грамада), «Зелёные», Аграрная партия,
Патриотическая партия, БХД, Партия свободы и прогресса.

## Возможности

- 🧭 **Компас** с выбором осей, плавным перемещением точек, оболочками лагерей (морфинг) и подсказками
- 🃏 **Сайдбар-карта**: список партий по мотивам «мандаты в парламенте»; по клику карта переворачивается
  слева направо, как игральная, и показывает подробную карточку партии (листание стрелками, свайпами, клавиатурой)
- 📊 **Аналитика**: полукруг парламента (110 мест), доли мандатов, рейтинг по оси, радар сравнения,
  разрыв между лагерями, матрица близости партий
- 🕰 **Хронология** партийной системы с 1988 года
- 🌗 Светлая и тёмная темы, адаптив под телефон, поддержка `prefers-reduced-motion`

## Запуск

Сборка не нужна — чистые HTML, CSS и JavaScript без зависимостей.

```bash
# вариант 1: просто открыть index.html в браузере
# вариант 2: локальный сервер
python3 -m http.server 8000
# → http://localhost:8000
```

Сайт можно опубликовать на GitHub Pages: Settings → Pages → Deploy from a branch → корень репозитория.

## Структура

```
index.html        разметка страницы
css/styles.css    дизайн-система, темы, анимации
js/data.js        оси, партии, координаты, хронология — всё редактируется здесь
js/app.js         компас, сайдбар-карта, тема, навигация
js/charts.js      графики и диаграммы на SVG
assets/           иконка
```

Чтобы поправить позицию партии или добавить новую, достаточно изменить `js/data.js`.

## Методология и дисклеймер

Позиции партий — **экспертная оценка** по шкале от −10 до +10 на основе программ, публичных заявлений
и политической практики. Это не официальная позиция самих партий. Проект носит образовательный характер
и не агитирует ни за одну политическую силу.
